# 点餐微信小程序（可维护版落地骨架）

这是一个可直接继续开发的「微信点餐小程序 + 后端 API」基础工程骨架，重点是：

- 分层清晰
- 命名统一
- 易于扩展
- 新人易接手

## 目录结构

- `miniprogram/`：微信小程序端（原生）
- `backend/`：后端服务（Node.js + Nest 风格分层）
- `docs/`：产品、接口、数据结构文档

## 第一阶段功能（MVP）

- 菜单浏览
- 购物车
- 下单
- 订单状态查询
- 商家接单（后端预留）

## 快速开发建议

1. 先按 `docs/api-spec.md` 实现后端接口。
2. 小程序先打通：菜单 -> 购物车 -> 提交订单。
3. 支付可先用「模拟支付状态」联调，后续替换微信支付。
